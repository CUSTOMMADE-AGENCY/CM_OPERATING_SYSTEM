# Governance Rules

## Purpose

These rules protect the Custommade Agency Int. B.V. operating system from becoming an uncontrolled file dump. GitHub is the structured source of truth for how the business runs.

## Repository rules

1. GitHub contains workflows, governance, SOPs, playbooks and system documentation only.
2. Google Drive contains live client folders, signed documents, deliverables and files.
3. ClickUp contains execution, pipeline and tasks.
4. Gmail contains communication templates and correspondence.
5. Do not commit signed contracts, confidential client files or private deal materials.
6. Do not copy old Drive chaos into GitHub.
7. Do not create duplicate folders for the same process.
8. Do not commit random exports or unmanaged data dumps.
9. Do not use `final_final`, `newest`, `latest`, `copy`, or similar uncontrolled filenames.
10. Every new document must have an owner, purpose, scope and update cadence.

## Approved top-level documentation lanes

- `00_governance`
- `01_master_boutique`
- `02_artist_management`
- `03_shared_services`
- `04_systems`

## Change control

- Small corrections may be committed directly through the normal review process.
- Workflow changes require a documented rationale, affected systems and owner approval.
- Major structural changes require updates to governance, Drive, ClickUp and as-built documentation.

## Escalation

If content does not clearly belong in GitHub, Drive, ClickUp or Gmail, pause and decide the correct system before creating files.
