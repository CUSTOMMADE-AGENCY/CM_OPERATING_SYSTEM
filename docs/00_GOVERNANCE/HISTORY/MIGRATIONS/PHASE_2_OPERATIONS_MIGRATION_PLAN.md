# Phase 2 Operations Migration Plan

**Status:** execution baseline
**Scope:** documentation-only Operations consolidation
**Canonical target:** `docs/05_OPERATIONS/`

## Guardrails

- This phase does not repeat Phase 1 and does not alter governance content except Phase 2 status records.
- Templates, business lanes, live automations, scripts and technical logic are frozen. No deletion is permitted.
- Git history is the file-level rollback mechanism; moves use `git mv`.
- Historical references under `docs/00_GOVERNANCE/HISTORY/` remain audit evidence.

## Classification decisions

External-platform system documents (Google Drive, ClickUp, Gmail and readiness audits) remain in `docs/04_SYSTEMS/`. Lane-specific shared-service procedures remain in place. The three root playbooks and their Agent variants differ byte-for-byte; the root variants remain at their existing paths and the Agent variants move without overwrite. Consolidation is therefore deliberately deferred.
