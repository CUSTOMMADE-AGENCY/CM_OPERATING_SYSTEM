# Architecture Decision Records

## Doel

Deze directory bevat de formele Architecture Decision Records (ADR's) voor wijzigingen aan de CM Operating System-architectuur na CM OS Baseline V1.0.

## Governance

Vanaf CM OS Baseline V1.0 is de productiearchitectuur vastgesteld. Wijzigingen aan Drive Structure, Folder Standards, Map Specifications, Governance, Templates, Workflows, SOPs, Playbooks of Agent Passports mogen uitsluitend via een ADR en Pull Request worden voorgesteld en doorgevoerd.

## Verplichte route

1. Maak een nieuwe ADR in deze directory.
2. Beschrijf context, besluit, impact, migratie, risico's en rollback.
3. Werk waar nodig `DECISION_LOG.md` en `CM_SYSTEM_DECISION_MATRIX.md` bij.
4. Open een Pull Request met CM CONTROL AGENT review.
5. Merge pas na repository-owner approval.

## Statussen

- Proposed
- Accepted
- Superseded
- Rejected
