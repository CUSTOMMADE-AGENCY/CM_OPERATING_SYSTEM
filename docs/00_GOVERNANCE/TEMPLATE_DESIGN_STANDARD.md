# TEMPLATE DESIGN STANDARD

## DOEL

Dit document definieert de ontwerpstandaard voor alle CM templates.

Templates zijn operationele tools.

Templates zijn geen SOP's.

Templates zijn geen rapporten.

Templates zijn geen strategiedocumenten.

Een template moet een gebruiker helpen om een taak sneller, consistenter en foutloos uit te voeren.

## KERNPRINCIPE

Een template moet binnen 10 seconden scanbaar zijn.

Een gebruiker moet direct begrijpen:

- Wat dit document is
- Waarom het gebruikt wordt
- Wat ingevuld moet worden
- Wat de volgende stap is

## ONTWERPPRINCIPES

Alle templates moeten:

- Overzichtelijk zijn
- Direct bruikbaar zijn
- Praktisch zijn
- Actiegericht zijn
- Compact zijn
- Consistent zijn

## VOORKEUR

Gebruik waar mogelijk:

- [ ] Checklists
- [ ] Tabellen
- [ ] Statusvelden
- [ ] KPI blokken
- [ ] Samenvattingen
- [ ] Beslismomenten
- [ ] Actiepunten

## VERMIJDEN

Geen:

- Lange paragrafen
- Essays
- Overmatige toelichtingen
- Dubbele vragen
- Theoretische uitleg
- Consultancy-jargon
- Open tekstvelden zonder duidelijk doel

## TEMPLATE STRUCTUUR

Elke template bevat bij voorkeur:

### OVERVIEW

Korte samenvatting.

### STATUS

Huidige status.

### CHECKLIST

Concrete acties.

### BELANGRIJKE INFORMATIE

Alleen noodzakelijke informatie.

### VOLGENDE STAP

Duidelijke vervolgstap.

## DESIGN STANDAARD

| Onderdeel | Standaard |
| --- | --- |
| Lettertype | Montserrat |
| Body | 10 pt |
| Hoofdtitels | Heading 2, vet, hoofdletters |
| Subtitels | Heading 3, vet, hoofdletters |
| Kleuren | Niet gebruiken |
| Emoji's | Niet gebruiken |

## KWALITEITSTEST

Een template is alleen goedgekeurd wanneer:

1. Een stagiair deze zelfstandig kan gebruiken.
2. De gebruiker geen extra uitleg nodig heeft.
3. Het document direct tot actie leidt.
4. De output consistent is.

## CM REGEL

Een template moet voelen als een operationele tool.

Niet als een notitieblok.

Niet als een rapport.

Niet als een consultancydocument.
