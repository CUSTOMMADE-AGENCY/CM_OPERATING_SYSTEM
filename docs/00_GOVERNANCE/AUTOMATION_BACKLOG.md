# Automation Backlog

De automation backlog verzamelt terugkerend werk dat CM kan versimpelen, automatiseren of foutlozer maken. Elk item start vanuit een concreet probleem, niet vanuit een toolwens.

## Statussen

- IDEA
- REVIEW
- TEST
- BUILD
- ACTIVE
- ARCHIVED

| AUTOMATION | PROBLEM | TOOL | IMPACT | PRIORITY | OWNER | STATUS |
|---|---|---|---|---|---|---|
| Naam van automation | Welk terugkerend probleem lost dit op? | Tool of stack | Verwachte tijdwinst, foutreductie of kwaliteitswinst | High / Medium / Low | Naam/rol | IDEA / REVIEW / TEST / BUILD / ACTIVE / ARCHIVED |
