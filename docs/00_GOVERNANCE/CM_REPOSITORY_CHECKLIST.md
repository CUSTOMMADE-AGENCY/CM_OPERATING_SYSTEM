# CM Repository Checklist

## Verplichte controle vóór merge

- [ ] Wijziging past binnen de goedgekeurde repositorystructuur.
- [ ] README en AS_BUILT spreken elkaar niet tegen.
- [ ] GOVERNANCE_RULES en DECISION_LOG zijn gecontroleerd.
- [ ] CM_SOURCE_OF_TRUTH is gerespecteerd.
- [ ] Change Impact Matrix is uitgevoerd.
- [ ] Geen dubbele documenten of parallelle Sources of Truth.
- [ ] Geen vertrouwelijke clientinformatie of getekende contracten.
- [ ] Interne documentatie is professioneel Nederlands.
- [ ] Officiële CM-termen zijn exact behouden.
- [ ] Bestands- en mapnamen voldoen aan Naming Conventions.
- [ ] Links en verwijzingen zijn gecontroleerd.
- [ ] Owner, doel en toepassingsgebied zijn duidelijk.
- [ ] Toolgrenzen zijn vastgelegd.
- [ ] Relevante Workflow, SOP, Playbook, Agent en Automation zijn meegecontroleerd.
- [ ] Verwijderingen zijn expliciet goedgekeurd.
- [ ] Templates zijn niet gewijzigd tijdens de Repository Recovery.
- [ ] Pull Request bevat impactanalyse, testresultaat en open punten.
- [ ] Sophia / process owner heeft review uitgevoerd.

## Completion standard

Een Pull Request mag pas worden gemerged wanneer alle relevante punten zijn afgevinkt of een expliciete, gedocumenteerde uitzondering is goedgekeurd.
