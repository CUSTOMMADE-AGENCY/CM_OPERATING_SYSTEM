# CM Governance Matrix

## Doel

Bepalen welk document of systeem per onderwerp leidend is.

| Onderwerp | Leidend document of systeem |
|---|---|
| Repositoryarchitectuur | `README.md` + `AS_BUILT_DOCUMENTATION.md` |
| Governanceprioriteit | `GOVERNANCE_RULES.md` + `DECISION_LOG.md` |
| Google Drive-structuur | `DRIVE_STRUCTURE.md` |
| Systeemrollen | `CM_SOURCE_OF_TRUTH.md` |
| Workflows | `docs/05_OPERATIONS/WORKFLOWS/` |
| SOPs | `docs/05_OPERATIONS/SOPS/` |
| Playbooks | `docs/05_OPERATIONS/PLAYBOOKS/` |
| Automations | `docs/05_OPERATIONS/AUTOMATIONS/` |
| Agents | `docs/05_OPERATIONS/AGENTS/` |
| Knowledge Base | `docs/05_OPERATIONS/KNOWLEDGE_BASE/` |
| Templates | huidige templatebron; ongewijzigd tijdens recovery |
| Artist Management | `docs/02_ARTIST_MANAGEMENT/` |
| Master Boutique | `docs/01_MASTER_BOUTIQUE/` |
| Clients | `docs/03_CLIENTS/` |
| Deals | `docs/04_DEALS/` |
| Finance | Moneybird + `docs/06_FINANCE/` voor systeemdocumentatie |
| Legal | `docs/07_LEGAL/` |
| Marketing | `docs/08_MARKETING/` |
| Content | `docs/09_CONTENT/` |

## Regel

Een document mag geen alternatieve Source of Truth introduceren. Bij conflict geldt `CM_SOURCE_OF_TRUTH.md` en daarna `DECISION_LOG.md`.
