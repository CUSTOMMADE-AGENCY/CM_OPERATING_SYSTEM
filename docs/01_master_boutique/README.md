## Operating scope

This lane covers catalog acquisitions, master rights deals, publishing rights deals, rights brokerage, buyer outreach, data rooms, LOI / APA / closing, and success-fee revenue.

## Core standards

- Separate transaction files from artist-management files.
- Keep confidential deal files and signed documents in Drive only.
- Track execution stages in ClickUp.
- Use Gmail templates for consistent buyer and seller communication.
- Keep GitHub limited to playbooks, workflows, and reusable operating standards.
