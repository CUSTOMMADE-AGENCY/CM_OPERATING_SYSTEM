# Buyer Outreach Workflow

## Purpose

Run controlled outreach to qualified buyers while protecting confidentiality and seller leverage.

## Steps

1. Build buyer universe by buyer type, mandate and relationship strength.
2. Approve outreach list internally.
3. Send non-confidential teaser or introductory email.
4. Log buyer response in ClickUp.
5. Run qualification call when interest is confirmed.
6. Send NDA only to qualified buyers.
7. Grant data-room access according to the access model.
8. Maintain consistent timelines and Q&A discipline.

## Quality checks

- No confidential data before NDA.
- No unapproved buyer access.
- Every buyer has a status and next action.

## Storage and tooling boundaries
- GitHub stores this workflow, governance, SOP and system documentation.
- Google Drive stores live client folders, signed documents, deliverables and working files.
- ClickUp stores execution, pipeline stages, owners, due dates and task evidence.
- Gmail stores correspondence and approved communication templates.

## Repository hygiene
- Do not commit signed contracts, confidential client files, exports, duplicate folders or ad hoc drafts.
- Use clear version history through commits and pull requests instead of `final_final` filenames.
- Keep client-specific details in the appropriate live workspace, not in this repository.
