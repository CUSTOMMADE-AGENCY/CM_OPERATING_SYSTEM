# Finance

## Doel

Deze lane ontsluit finance intake, revenue tracking, royalties, open items, invoice controls, reconciliation, forecasting, reporting en Moneybird governance.

## Grenzen

Git bevat alleen procesdocumentatie: geen bedragen, facturen, bankafschriften, exports, betaalgegevens of andere live financiële data. Moneybird en de goedgekeurde Drive-locaties blijven de operationele systemen.
