## Core CM rule

NO BRANDBOOK = NO STRATEGY
NO STRATEGY = NO RELEASE PLAN
NO RELEASE PLAN = NO EXECUTION

## Operating scope

This lane covers artist intake, fit checks, brand audits, brandbooks, business audits, roadmaps, release strategy, rights and royalty audits, monthly management, communication, approvals, close-out, and next-phase upsell.
