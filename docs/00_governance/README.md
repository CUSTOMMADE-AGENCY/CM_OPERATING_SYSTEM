# Governance

This section defines the shared operating rules for CM. It applies to both Master Boutique and Artist Management unless a lane-specific document provides a more specific standard.

## Contents

- Drive structure and information ownership.
- Naming conventions and document standards.
- Version control and archive rules.
- Workflow documentation requirements.
- As-built documentation requirements.

## Operating principle

Governance documents should be short, enforceable, and reusable. If a standard applies to both revenue engines, it belongs here or in shared services. If it applies to only one lane, it belongs in that lane.

## Required review triggers

Review governance documents when CM adds a new tool, changes a client workflow, changes a deal workflow, or finds duplicate / conflicting documents in use.
