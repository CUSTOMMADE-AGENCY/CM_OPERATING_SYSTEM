# Naming Conventions

## Repository files

- Use uppercase names with underscores: `ARTIST_INTAKE_FLOW.md`.
- Use singular, descriptive business terms.
- Avoid dates in file names unless the date is legally or operationally required.
- Avoid words such as `draft`, `copy`, `new`, `latest`, or `final_final`.

## Version labels

Use document headers or document history for versions:

- `V1.0` first approved release.
- `V1.1` minor update.
- `V2.0` major redesign.

## Client and deal folders

Use a clean pattern in Drive and ClickUp:

- Clients: `CLIENTNAME_SERVICE_YEAR`
- Deals: `ASSETNAME_RIGHTSTYPE_YEAR`
- Deliverables: `CLIENTNAME_DELIVERABLE_V1.0`

## Naming control

If two documents appear to cover the same process, pause and consolidate before creating a new file.
