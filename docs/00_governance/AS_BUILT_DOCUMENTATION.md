# As-Built Documentation Standard

As-built documentation records what was actually implemented in a system, not what was planned.

## When required

Create or update as-built documentation when CM implements or changes:

- Google Drive structures.
- ClickUp spaces, lists, statuses, or custom fields.
- Gmail templates.
- Automations.
- AI agents or scripted workflows.

## Required sections

- System name.
- Implementation date.
- Owner.
- Current structure.
- Rules and permissions.
- Known limitations.
- Maintenance routine.

## Quality rule

A system is not complete until its as-built documentation explains how to inspect, maintain, and safely change it.
