# Workflow Documentation Standard

Every workflow must be documented before it is treated as operational.

## Required sections

1. Purpose.
2. Trigger.
3. Inputs.
4. Workflow steps.
5. Required approvals.
6. Outputs.
7. Handover destination.
8. Quality checks.

## Workflow ownership

- Master Boutique owns transaction workflows.
- Artist Management owns artist-service workflows.
- Shared Services owns reusable support workflows.
- Systems owns tool configuration and automation documentation.

## Change rule

If a ClickUp status, Drive folder, Gmail template, or approval point changes, update the matching workflow document.
