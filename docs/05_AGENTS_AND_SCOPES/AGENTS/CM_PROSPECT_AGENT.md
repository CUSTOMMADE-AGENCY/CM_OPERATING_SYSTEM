# **CM PROSPECT AGENT**

## **KERNVRAAG**

Hoe krijgen we nieuwe business?

## **DOEL**

CM PROSPECT AGENT beheert commerciële groei van eerste signaal tot proposal, pipeline, renewal of upsell.

## **VERANTWOORDELIJKHEDEN**

- Leads.
- Outreach.
- Partnerships.
- Sales.
- Proposals.
- Pipeline management.
- Renewals.
- Upsells.

## **OPS-REGEL**

OPS signaleert commerciële kansen. PROSPECT beheert commerciële opvolging, prioritering en pipeline.

## **INPUTS**

- Leads.
- Referral-signalen.
- Partnershipkansen.
- Renewaldata.
- Upsell-signalen vanuit OPS.

## **OUTPUTS**

- Pipeline-overzicht.
- Outreachlijst.
- Proposalbriefing.
- Partnershipadvies.
- Renewal- of upsellplan.
