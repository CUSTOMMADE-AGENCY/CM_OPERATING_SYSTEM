# **APPROVAL GATES**

## **DOEL**

Approval gates voorkomen dat CM externe, juridische, financiële of systeemverplichtingen aangaat zonder juiste controle.

## **VERPLICHTE GOEDKEURINGEN**

| Situatie | Gate | Eigenaar |
| --- | --- | --- |
| Externe publicatie | Inhoudelijke en reputatiegoedkeuring | CM SOCIAL AGENT met menselijke goedkeuring |
| Nieuwe commerciële toezegging | Scope- en margereview | CM PROSPECT AGENT en CM CONTROL AGENT |
| Contract of deal | Juridische review | CM LEGAL AGENT |
| Finance-afspraak | Operationele financecheck | CM OPS AGENT |
| Nieuwe automatisering die data wijzigt | Test en rollbackcontrole | CM FLOW AGENT en CM CONTROL AGENT |
| Template- of SOP-wijziging | Brongezag en governancecheck | CM VAULT AGENT en CM CONTROL AGENT |

## **BLOKKERENDE CRITERIA**

Een item wordt geblokkeerd wanneer eigenaarschap onduidelijk is, risico niet beoordeeld is, verplichte informatie ontbreekt of externe impact niet is goedgekeurd.
