# **HANDOFF CHAIN**

## **DOEL**

De handoff chain borgt dat werk tussen agents overdraagbaar blijft zonder verlies van context, eigenaar of besluitstatus.

## **STANDAARD HANDOFF**

| Van | Naar | Trigger | Vereiste overdracht |
| --- | --- | --- | --- |
| CM CONTROL AGENT | Alle agents | Goedgekeurde routing | Doel, prioriteit, risico en deadline |
| CM PROSPECT AGENT | CM OPS AGENT | Gewonnen project of renewal | Scope, afspraken, proposal en startvoorwaarden |
| CM OPS AGENT | CM PROSPECT AGENT | Upsell- of renewal-signaal | Context, timing, klantbehoefte en commerciële kans |
| CM OPS AGENT | CM LEGAL AGENT | Contract-, rechten- of dealvraag | Dealcontext, deadlines en open punten |
| CM SOCIAL AGENT | CM VAULT AGENT | Goedgekeurde case study of asset | Definitieve bron, eigenaar en opslaglocatie |
| CM VAULT AGENT | CM FLOW AGENT | Structuur of template vraagt automatisering | Bronstructuur, velden en governancebeperkingen |
| CM FLOW AGENT | CM OPS AGENT | Automatisering raakt deliveryproces | Werking, monitoring en failure handling |

## **HANDOFF-CHECKLIST**

- Eigenaar benoemd.
- Status benoemd.
- Volgende actie benoemd.
- Deadline of reviewmoment benoemd.
- Bronlocatie benoemd.
- Risico’s en aannames benoemd.
