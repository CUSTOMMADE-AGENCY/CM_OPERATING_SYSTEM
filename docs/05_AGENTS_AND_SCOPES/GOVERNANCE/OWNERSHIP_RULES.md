# **OWNERSHIP RULES**

## **DOEL**

Deze regels bepalen welke CM-agent eigenaar is van welk besluit, document, proces of systeemonderdeel.

## **BASISREGELS**

- Eén taak heeft één primaire eigenaar.
- De eigenaar bewaakt voortgang, volledigheid en overdracht.
- Review door een andere agent verandert het primaire eigenaarschap niet.
- Bij conflict beslist CM CONTROL AGENT over routing.

## **EIGENAARSCHAP PER DOMEIN**

| Domein | Eigenaar |
| --- | --- |
| Governance en prioriteiten | CM CONTROL AGENT |
| Projecten, planning en finance | CM OPS AGENT |
| Leads, sales en pipeline | CM PROSPECT AGENT |
| Content en publicaties | CM SOCIAL AGENT |
| Contracten, rechten en deals | CM LEGAL AGENT |
| Bronnen, templates en archief | CM VAULT AGENT |
| Automatiseringen en integraties | CM FLOW AGENT |

## **NIET-OVERDRAGEN REGELS**

- CM CONTROL AGENT voert geen operationele taken uit.
- CM FLOW AGENT bezit geen inhoud.
- CM VAULT AGENT verwijdert nooit bronnen.
- CM SOCIAL AGENT publiceert nooit zonder goedkeuring.
- CM LEGAL AGENT bezit alle dealreviews.
