# File Management

## Purpose

Keep files easy to find, permissioned correctly, and free of duplicates.

## Inputs

- Lane
- Client or deal name
- File category
- Confidentiality level

## Workflow

1. Store GitHub materials only when they are standards or playbooks.
2. Store execution and confidential files in Drive.
3. Use approved folder structures.
4. Archive old versions.
5. Remove duplicate or unmanaged files.

## Outputs

- Updated system of record.
- Clear owner and next action.
- Files stored in the correct location.

## Version

V1.0 starter operating standard.
