# Meeting Process

## Purpose

Run professional meetings with clear agendas, decisions, and follow-up.

## Inputs

- Meeting objective
- Attendees
- Agenda
- Open decisions

## Workflow

1. Send agenda before meeting.
2. Start with required decisions.
3. Capture notes and actions.
4. Assign owners and deadlines.
5. Send recap and update ClickUp.

## Outputs

- Updated system of record.
- Clear owner and next action.
- Files stored in the correct location.

## Version

V1.0 starter operating standard.
