# Client Onboarding

## Purpose

Start approved work consistently after contract and payment conditions are met.

## Inputs

- Signed agreement stored in Drive
- Payment confirmation or approved billing schedule
- Client contact details
- Approved scope

## Workflow

1. Create client or deal folder in Drive.
2. Create ClickUp task/list using the correct lane statuses.
3. Send onboarding mail with next steps and communication rules.
4. Collect required assets and access.
5. Confirm kickoff meeting and first milestone.

## Outputs

- Updated system of record.
- Clear owner and next action.
- Files stored in the correct location.

## Version

V1.0 starter operating standard.
