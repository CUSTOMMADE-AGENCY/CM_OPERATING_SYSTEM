# Proposal Workflow

## Purpose

Convert qualified opportunities into clear, scoped, and priced proposals.

## Inputs

- Qualified need
- Recommended service
- Timeline
- Fee model
- Decision-maker details

## Workflow

1. Confirm problem and desired outcome.
2. Select the correct lane and offer type.
3. Define scope, exclusions, timeline, and fee.
4. Review internally for fit and capacity.
5. Send proposal and track follow-up.

## Outputs

- Updated system of record.
- Clear owner and next action.
- Files stored in the correct location.

## Version

V1.0 starter operating standard.
