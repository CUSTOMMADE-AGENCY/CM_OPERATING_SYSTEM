# Communication Process

## Purpose

Standardize external communication across email, meetings, and task updates.

## Inputs

- Recipient group
- Communication objective
- Approved template if available
- Confidentiality level

## Workflow

1. Choose the correct channel.
2. Use the approved template or tone standard.
3. Keep messages concise and action-oriented.
4. Record decisions in writing.
5. File important correspondence in the correct system.

## Outputs

- Updated system of record.
- Clear owner and next action.
- Files stored in the correct location.

## Version

V1.0 starter operating standard.
