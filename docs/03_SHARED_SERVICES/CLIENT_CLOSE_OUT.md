# Client Close-Out

## Purpose

End projects cleanly with final delivery, archive, and next-step clarity.

## Inputs

- Completed scope
- Deliverables register
- Open issues
- Payment status

## Workflow

1. Confirm all deliverables are final.
2. Send close-out mail and final links.
3. Request feedback or approval.
4. Archive files and update ClickUp.
5. Offer next phase where relevant.

## Outputs

- Updated system of record.
- Clear owner and next action.
- Files stored in the correct location.

## Version

V1.0 starter operating standard.
