# Systems Knowledge

## Doel

Deze map bevat interne systeemkennis en referentiedocumentatie die nodig is om
de operationele architectuur te begrijpen. Uitvoerbare automatisering, scripts
en documentatie voor externe platformen horen hier niet thuis.

## Register

- [`CM_ARCHITECTURE_MAP.md`](CM_ARCHITECTURE_MAP.md) — overzicht van de
  repository- en systeemarchitectuur.
- [`CM_VAULT_V1.md`](CM_VAULT_V1.md) — referentie voor de CM Vault-inrichting.

`docs/04_SYSTEMS/`. Automation-specificaties staan onder
`docs/05_OPERATIONS/AUTOMATIONS/`. Live technische logica blijft in `.github/`
en `scripts/`.
