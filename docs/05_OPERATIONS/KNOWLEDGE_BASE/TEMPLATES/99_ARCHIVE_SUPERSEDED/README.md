## Status

## Waarom gearchiveerd

De governance verbiedt duplicate template-locaties (`TEMPLATE_REVIEW_PROCESS`, `GOVERNANCE_RULES`). Er bestonden meerdere parallelle sets die split-brain governance veroorzaakten: een agent of automation kon de verkeerde versie pakken. Deze zijn hierheen verplaatst zodat er per template nog maar één canonieke locatie is.
