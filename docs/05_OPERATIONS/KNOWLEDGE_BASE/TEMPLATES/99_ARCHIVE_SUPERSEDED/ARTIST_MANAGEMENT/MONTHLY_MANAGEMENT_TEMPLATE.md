## ClickUp list setup

Create a recurring ClickUp task named `AM - Monthly Management Review - [Artist Name] - [Month]`.

## Required custom fields

| Field | Type | Required |
|---|---|---|
| Artist | Text | Yes |
| Month | Date/Text | Yes |
| Manager | People | Yes |
| Health status | Dropdown | Yes |
| Budget items | Text | No |
| Decisions needed | Text | Yes |
| Blockers | Text | Yes |
| Next review date | Date | Yes |

## Statuses

1. Prep.
2. In review.
3. Waiting for approval.
4. Execution follow-up.
5. Complete.

## Recurring task sections

| Section | Required content |
|---|---|
| Previous-month review | Completed work, missed deadlines, blockers, wins and lessons. |
| Workstream updates | Brand, release, rights/business, partnerships, deals, content and team. |
| Decisions | Money, rights, contracts, public messaging, partnerships, release timing and access. |
| Risks | New risks, changed risk levels, mitigation owner and escalation trigger. |
| Next-month priorities | Top priorities, owner, due date, dependency and KPI. |
| Client communication | Summary sent, approvals captured and follow-up tasks assigned. |

## Automation suggestions

- Create follow-up tasks for each unchecked next action.
- Notify the artist manager when any blocker is marked high risk.
- Schedule the next monthly review when the current review is completed.
