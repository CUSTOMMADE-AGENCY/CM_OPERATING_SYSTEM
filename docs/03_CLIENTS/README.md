# Clients

## Doel

Deze lane beheert het generieke proces voor niet-artist clients: intake, Fit Check, Scope, Proposal, Onboarding, delivery, review, Upsell, close-out en account ownership.

## Afbakening

- Alleen procesdocumentatie staat in Git; geen live clientdata, contracten of deliverables.
- Artist-specifieke processen blijven in `docs/02_ARTIST_MANAGEMENT/`.
- Dealcases en transactiedocumentatie horen in `docs/04_DEALS/`.
- Google Drive bewaart live dossiers; ClickUp bewaart uitvoering.
