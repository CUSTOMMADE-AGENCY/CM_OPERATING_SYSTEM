# ARTIST ONBOARDING TEMPLATE

## ClickUp list setup

Create a ClickUp list named `AM - Artist Onboarding - [Artist Name]`.

## Required custom fields

| Field | Type | Required |
|---|---|---|
| Artist | Text | Yes |
| Scope | Dropdown | Yes |
| Owner | People | Yes |
| Approval owner | People/Text | Yes |
| Drive link | URL | Yes |
| Agreement link | URL | Yes |
| Health status | Dropdown | Yes |
| Next review date | Date | Yes |
| Risk level | Dropdown | Yes |

## Statuses

1. Not started.
2. Waiting for input.
3. In progress.
4. Needs approval.
5. Blocked.
6. Complete.

## Task groups

| Group | Required tasks |
|---|---|
| Engagement basis | Confirm Scope, fee, term, exclusions, payment status and approval requirements. |
| Workspace setup | Create Drive folder, ClickUp list, decision log, risk log and deliverables register. |
| Artist inputs | Collect goals, assets, links, analytics, team roster, rights summaries and release deadlines. |
| Approvals | Complete Artist Approval Matrix and written confirmation of decision owners. |
| Communication | Confirm cadence, channels, response expectations and meeting schedule. |
| First execution | Create first roadmap, immediate next actions, missing-input tasks and escalation path. |
| Handover | Send onboarding summary and move active work into Monthly Management. |

## Automation suggestions

- When a task moves to `Needs approval`, notify the approval owner.
- When a due date passes on `Waiting for input`, escalate to the artist manager.
- When all required onboarding tasks are complete, create the first Monthly Management Review task.
