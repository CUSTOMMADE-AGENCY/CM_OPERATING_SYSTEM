# 00 Artist Management Map

## Doel

Deze map is het canonical entrypoint voor de Artist Management-lane. Gebruik dit document om snel te bepalen welke Workflow, SOP, Matrix, Checklist, Template of ClickUp-template hoort bij een artist-managementvraag.

## System of record

| Laag | System of record | Gebruik |
|---|---|---|
| Operating rules | GitHub | Workflows, SOP's, matrices, checklists en reusable templates. |
| Execution | ClickUp | Tasks, owners, statussen, deadlines, approvals, blockers en bewijs. |
| Client files | Google Drive | Artist-specifieke assets, live deliverables, contracten, exports en bronbestanden. |
| Correspondentie | Gmail | Approved communicatie, confirmations en external follow-up. |

## Lifecycle volgorde

1. Artist Onboarding.
2. Brand Audit.
3. Artist Brandbook.
4. Artist Roadmap.
5. Release Strategy.
6. Monthly Management.
7. Deal Negotiation of Brand Partnership wanneer opportunities ontstaan.
8. Artist Offboarding bij einde project, retainer, pauze of overdracht.

## Operating rules

- Start geen Workflow zonder Scope, owner, approval path en system of record.
- Leg elke money, rights, contract, release, public messaging, partnership en access decision schriftelijk vast.
- Gebruik de Artist Approval Matrix wanneer besluitbevoegdheid onduidelijk is.
- Maak elke live action aan in ClickUp met owner, due date, status, source link en required evidence.
- Bewaar artist-specifieke bestanden uitsluitend in de juiste Google Drive-clientmap.
