# ClickUp Structure

ClickUp is the source for tasks, pipeline, statuses, execution, and deadlines.

## Spaces / lists

Use separate execution areas for each revenue engine.

## MASTER_BOUTIQUE

### Statuses

1. LEAD
2. INTRODUCER
3. INTAKE
4. RIGHTS REVIEW
5. FINANCIAL REVIEW
6. BUYER TARGETING
7. NDA
8. TEASER
9. PORTAL ACCESS
10. BUYER QUALIFICATION
11. DATA ROOM
12. INDICATIVE OFFER
13. LOI
14. DUE DILIGENCE
15. APA REVIEW
16. CLOSING
17. SUCCESS FEE
18. ARCHIVE

### Recommended fields

- Asset name.
- Rights type.
- Seller / introducer.
- Buyer target category.
- NDA status.
- Data-room access status.
- Fee trigger.

### Statuses

1. LEAD

4. BRANDBOOK

10. ONBOARDING
11. EXECUTION
12. DELIVERY

16. UPSELL
17. ARCHIVE

### Recommended fields

- Artist name.
- Service type.
- Current phase.
- Approval owner.
- Payment status.
- Next milestone.
- Scope risk.

## Rules

- Do not mix transaction and artist-service tasks in the same list.
- Use statuses as stage gates, not labels.
- Record decisions in task comments and store files in Drive.
