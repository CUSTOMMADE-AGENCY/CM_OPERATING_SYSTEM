# Automations

Automations should reduce manual repetition without creating hidden process logic.

## Approved automation areas

- Folder creation from approved templates.
- Required-file checks in GitHub.
- ClickUp status reminders.
- Gmail template usage and follow-up reminders.

## Automation rules

- Keep automations simple and auditable.
- Document every implemented automation as-built.
- Do not automate access to confidential folders without explicit permission rules.
- Avoid deep nested folder creation.

## Maintenance

Review automations quarterly or whenever a workflow changes.
